# Presentation implementation

29 October 2026.

The existing GitHub Pages portfolio uses original static HTML, CSS and JavaScript. Sanctir.com was a visual reference for restrained navy, white and muted gold, serif headings, thin rules and generous spacing. No Sanctir logo, brand text or image assets were copied. The monogram is an original text-based SVG.

Navigation follows a reader’s path: selected projects, evidence method, full public library, authorship and correction records. Public and private status is recorded separately; private drafts are not featured as public work.

The site has no build dependency, external font, tracker or third-party script. Navigation and project links work without JavaScript. JavaScript enhances filtering and the small-screen menu. Focus styles, a skip link, status announcements and reduced-motion handling are included.

Clinical manuscript content, source records, code and historical exports are maintained in their corresponding repositories. The presentation pass does not constitute a new clinical review.
